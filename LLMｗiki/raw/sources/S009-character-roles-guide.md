## 原始主要章節與對照摘要

1. **Main DPS（主輸出 / 前台站場）**
   - 負責大部分前台站場輸出時間，具備高額普攻/重擊強化或長持續時間技能。若切換離場往往會打斷其輸出狀態。
   - 例如：那維萊特（重擊站場）、雷電將軍（大招爆發期間站場）。
2. **Sub DPS（副輸出 / 後台輸出）**
   - 技能（元素戰技或爆發）具備脫手特性，施放後即可切換下場，由後台持續打出傷害並協同觸發元素反應。
   - 例如：芙寧娜（戰技召喚物後台協同輸出）。
3. **Support（輔助 / 增益與生存）**
   - 包含增益型輔助（Buffer，提供攻擊力/元素傷害/減抗）、控制型輔助（Crowd Control / 聚怪），以及生存位（Sustain：治療者 Healer、護盾 Shielder）。
   - 核心目標為提升主輸出爆發上限或維護全隊生存。
